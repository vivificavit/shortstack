# Release notes

Paste the text under each version into the "What's new" box for that release in Play Console. Keep it under 500 characters.

## 0.2.0 beta (versionCode 2)

```
New in this beta:
• All kids: pick "All kids" in the kid menu to see every kid's balance and latest entries on one screen. On an unfolded phone or a tablet they sit side by side.
• Choose your currency symbol from the menu
• Type amounts with a comma or a point
• Rename kids and categories without losing their entries
• Safer backups and a few fixes
Something wrong or confusing? Use the feedback link on the testing page.
```

## 0.1.0 beta (versionCode 1)

```
First beta of shortstack. Thanks for testing!
• Track each kid's allowance, spending and balance
• Savings goals with optional buy-by dates and a weekly amount to save
• Repeating entries, like a weekly allowance, added automatically
• Trends: balance over time and spending by category
• Backup, restore and CSV export
Everything stays on your phone. Something wrong or confusing? Use the feedback link on the testing page.
```
